# private workspace

this folder is yours. it is not part of the marketing-os distribution and should not be
committed to the public repository.

layout:

- `business.md` - the brief everything else is built from
- `operating-rules.md` - the rules the agent reads first
- `sources/` - raw customer words and other evidence you collected
- `campaigns/` - one folder per campaign: the pack, the page copy, the build sheet
- `tests/` - one folder per test: plan, data exports, readings, result
- `proposals/` - what the agent suggests, none of it approved
- `learnings/` - what you approved, and only that
- `output/` - drafts, readings, run notes, demo output

start with `business.md`, then run `doctor`.
