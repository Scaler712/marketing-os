# campaigns

one folder per campaign, named `cNN-short-name`, numbered in the order you built them.
never write into an existing campaign folder.

inside a campaign folder:

- `pack.md` - claim table, the one difference, ad versions, page copy, posts, follow-up
- `production.md` - the build sheet and the owner check list
- `work/` - options and notes that did not make it into the pack
