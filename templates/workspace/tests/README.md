# tests

one folder per test, named `tNN-short-name`. never reuse a folder.

inside a test folder:

- `plan.md` - the question, the one difference, the cap, the end rule, the launch record
- `data/` - exports, with dates in the file names: `ads-YYYY-MM-DD.csv`, `sales-YYYY-MM-DD.csv`
- `readings/` - one reading per date, never overwritten
- `results.md` - written once, at the end, and never overwritten
